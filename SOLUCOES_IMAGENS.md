# Fotografias ilustrativas — Nossas Soluções

As seis imagens em `public/images/solutions/` foram geradas para esta seção em 14/10/2026 com a ferramenta de geração de imagens do Codex e convertidas para WebP localmente.

| Arquivo | Representação |
| --- | --- |
| `acesso-facial.webp` | Pessoa usando terminal facial em entrada corporativa |
| `relogio-ponto.webp` | Funcionário registrando ponto por biometria |
| `catracas-entrada.webp` | Catracas automáticas em recepção corporativa |
| `cameras-seguranca.webp` | Câmeras de segurança em edifício corporativo |
| `edificio-comercial.webp` | Fachada de edifício comercial moderno |
| `instalacao-camera.webp` | Técnico instalando câmera em parede externa |

As imagens são ilustrativas, não retratam clientes, instalações realizadas nem modelos comerciais específicos. Não foram usados bancos de imagem ou fotografias de terceiros; não há licença externa de fotografia a registrar.
